# Igikoni - Online Food Ordering Application

## Description

This project consists of a frontend and backend application for an online food ordering platform.

## Running the Application
### Frontend

```bash
cd frontend
ng serve
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

## Build and Deployment

- Push the `main` branch to the remote Git repository  
- The application will be automatically deployed a few minutes later. Check status on https://dashboard.render.com/
